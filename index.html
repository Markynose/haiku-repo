Native Haiku fsn prototype

Standard Haiku controls around an original-SGI-fsn-derived software viewport, plus a small independent reusable UI library.

Install on Haiku x86_64

pkgman add-repo https://markynose.github.io/haiku-repo/
pkgman refresh
pkgman install fsn_native
# Optional development library:
pkgman install native_panels_devel

Launch FSN Native from Deskbar Applications to scan / automatically. The initial directory view shows / and its direct children; select a child to enter it. Escape then Overview shows the full scanned landscape. Scanning is bounded and cancelable; limits and skipped entries produce a labelled partial snapshot. For another folder: fsn-scan-view /boot/home/small-folder.

New in 0.2.1

Normal launch opens / through a bounded background scanner, with Cancel, retry and saved-scene fallback. Existing 0.2 features remain:

Exact 64-bit file sizes and directory totals; explicit read-only Haiku attributes and stored MIME; reusable native PropertyList control. Large-scene geometry is an identified modern adaptation. Ordinary filesystem browsing uses OS-mounted paths, not new drivers; ext4/Btrfs runtime mounts were not tested here.
