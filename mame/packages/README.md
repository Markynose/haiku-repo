# Experimental MAME SGI package

The matching native repository index is hosted one directory above. This separate repository preserves the vendor identity of the tested package and leaves the existing FSN index unchanged.

[Complete source, licences and limitations](../../MAME-SGI.md). IRIX 5.3 installation and two cold desktop launches were verified in a Haiku VM on 2026-11-02; warm restart failed and normal physical mouse behavior remains unverified. See [dated QA](../DESKTOP-QA.md). No ROMs, firmware, IRIX media or guest disks are distributed.
