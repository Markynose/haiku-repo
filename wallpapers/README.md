# Unix overflow wallpaper

[Download the 1366 × 768 T460 wallpaper](t460-unix-overflow.png).

A dense collage of 205 instances of 38 Haiku, CDE and Window Maker icons.
Original icon colours are preserved; the composition adds scaling, small rotations, overlap, shadows and a charcoal background.
